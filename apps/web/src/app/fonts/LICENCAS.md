# Fontes self-hosted

Subset `latin` baixado do Google Fonts (mesmos arquivos que o `next/font/google` usava):

| Arquivo | Família | Licença |
|---|---|---|
| `InterTight-latin-var.woff2` | Inter Tight (variável, usamos 300–700) | SIL Open Font License 1.1 |
| `InstrumentSerif-latin-regular.woff2`, `InstrumentSerif-latin-italic.woff2` | Instrument Serif | SIL Open Font License 1.1 |
| `GeistMono-latin-var.woff2` | Geist Mono (variável, usamos 400–500) | SIL Open Font License 1.1 |

Texto da licença: https://openfontlicense.org/open-font-license-official-text/

Para atualizar: baixe o CSS de `https://fonts.googleapis.com/css2?family=...` com um User-Agent de navegador moderno e pegue o `src` do bloco `/* latin */`.
